The methods of measuring the mean in grouped data are mainly three:

* Direct Method

* Assumed Mean Method

* Step-Deviation Method

### 1\. Direct Method

The mean is calculated using the formula:

\\bar{x}=\\frac{\\sum fx}{\\sum f}

Where:

* = frequency

* = class mark (midpoint of a class)

* = sum of frequency multiplied by class mark

* = total frequency

Example:

| Class interval | Frequency () | Midpoint () |     |
| -------------- | ------------ | ----------- | --- |
| 0–10           | 2            | 5           | 10  |
| 10–20          | 3            | 15          | 45  |
| 20–30          | 5            | 25          | 125 |
| Total          | 10           |             | 180 |

\\bar{x}=\\frac{180}{10}=\\boxed{18}

### 2\. Assumed Mean Method

The formula is:

\\bar{x}=A+\\frac{\\sum fd}{\\sum f}

Where:

* = assumed mean

* = frequency

* = class mark

This method is useful when the class marks are large and calculations using the direct method are inconvenient.

### 3\. Step-Deviation Method

The formula is:

\\bar{x}=A+\\frac{\\sum fu}{\\sum f}\\times h

Where:

* = assumed mean

* = common class width

* = frequency

This method is especially useful when class intervals have equal widths and the calculations can be simplified.

### Quick comparison

| Method         | Formula | Best used when          |
| -------------- | ------- | ----------------------- |
| Direct         |         | Calculations are simple |
| Assumed mean   |         | Class marks are large   |
| Step-deviation |         | Class widths are equal  |

Remember: All three methods give the same mean. They differ only in how the calculations are performed.
